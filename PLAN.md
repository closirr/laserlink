# LASERLINK — план розробки та публікації

## Мета
Повна, готова до публікації веб-гра (HTML5) у жанрі tower defense з «зірковою» механікою
ланцюгового підсилення лазерів (натхнення: Harvest: Massive Encounter), з меню, прогресією,
20+ рівнями, збалансованою економікою. Публікація: GitHub Pages + itch.io + подача на CrazyGames.

## Висновки дослідження ринку (вересень 2026)
- **Tower defense — зростаюча нішa** веб-ігор (CrazyGames має окрему категорію; розробники
  називають TD+idle/merge «booming niche»). Гіперказуал — #1 за сесіями, головоломки ~20%.
- **Retention — метрика #1** для Poki/CrazyGames. Перший сеанс ≥6 хв = ~20%+ Day1 retention;
  завантаження має тривати секунди (без ваги, без зовнішніх запитів під час гри).
- Успішні кейси соло-девів на Poki: BLUMGI (100M гравців за 2 роки), Vortella (5M геймплейів/міс).
- Монетизація: ревшара від рекламних показів платформи → потрібні перерви між хвилями
  (природні слоти для рекламних пауз платформ) і довгі сесії (багато рівнів).
- Вимоги платформ: HTML5, працює в iframe, ландшафт, миша+тач, без серверів, офлайн-ассети.

## Концепція гри: LASERLINK
**Жанр:** tower defense / стратегія в реальному часі на одній карті.
**Унікальна механіка (USP):** вежі-призми направляють промені у лазерні турелі й підсилюють їх.
Призми можна ланцюгувати (призма → призма → лазер = мультиплікативний буст) — «суперлазер»,
 що пробиває ворогів наскрізь. Головоломка розстановки + соковиті неонові промені.
**Економіка (з Harvest):** енергія тече з ядра; екстрактори на кристалах дають дохід;
 пілони розширюють мережу. Розширення території = ризик/нагорода.
**Хвилі монстрів** ідуть до Ядра; стіни переспрямовують потік (мейзинг, як у Desktop TD).
